A deadpan one-star review, 160 characters or fewer, of an everyday essential everyone relies on — the sun. A real complaint, filed in earnest, against a thing that cannot be fixed, with the sting in the last few words:

> One star. The sun has been running for four billion years and still has no dimmer switch.

## Run it

```sh
node main.ts
```

The program is fully deterministic — no network, no model calls, no randomness — and writes the review to `/output/entry.txt`.
